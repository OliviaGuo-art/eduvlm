\## 检索结果

\## 失败与边界案例



\### 生成截断



qa007 和 qa008 的直接回答均因达到输出长度限制而以 length 结束。两条回答的核心物理结论正确，但完整性记 0。RAG 十二条回答均以 stop 结束。



\### 引用格式失败



qa008 的 RAG 回答物理内容正确，也选择了正确的 uniform\_circular\_motion\_001，但生成了字面量【doc\_id】。因此引用编号有效性记 0。



该案例说明：



1\. 正确选择资料不等于引用格式一定合格；

2\. 引用编号需要程序自动校验；

3\. 后续提示词应加入具体正确示例，并明确禁止输出字面量【doc\_id】；

4\. 原始失败回答保留，不通过修改原始结果美化实验。



\### 库外行为



qa013 和 qa014 均回答正确。RAG 没有强行引用无关物理资料，能够根据图片和模型已有知识回答库外图片问题。



\## 成本与结论



RAG 总 Token 为 20287，直接回答为 16311，RAG 增加 3976 Token，相对增加约 24.4%。



在本测试集上，没有观察到 RAG 纠正直接回答物理错误的案例，因此不能声称 RAG 提高了正确率。当前主要收益是提供可核查证据和避免本实验中的生成截断。



样本量较小，题目属于基础物理，部分图片包含明显文字提示。最终结果仅适用于当前模型、数据集和实验配置。



原始 JSON、完整回答和评分工作簿不提交到 GitHub；本文档只记录汇总指标与失败分析。
